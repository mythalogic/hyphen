# setup_tools_createNewWorkspace

Minimal Python "Hello, World!" project scaffold.

## Quick start (Windows)

1. Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Install dev requirements:

```powershell
pip install -r requirements.txt
```

3. Run the program:

```powershell
python src\main.py
# or
python -m src.main
```

4. Run tests:

```powershell
python -m pytest -q
```
